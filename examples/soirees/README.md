# AS Event — Des jeux de soirée, surtout du blind test

**7 packs de 16 manches : 12 blind tests + 4 pauses sur la soirée (75 % de musique).** Au total : 84 extraits à préparer et 28 questions d’animation. Les thèmes changent les musiques, pas le principe de l’animation. Pas de quiz scolaire.

## À préparer avant de jouer

Chaque pack est une **trame à personnaliser**. Les 12 bonnes réponses du blind test sont déjà cochées ; associer tes extraits dans l’éditeur. Les pauses arrivent après chaque groupe de 3 morceaux. Elles sont communes aux packs : si tu enchaînes plusieurs packs, garde ces pauses une seule fois ou remplace-les par d’autres observations de la soirée pour éviter les répétitions.

- Manche 4 : prénom du DJ, proposé **Sylvain** (à confirmer).
- Manche 8 : **nombre réel de projecteurs**, à renseigner dans les choix. Aucun nombre n’a été inventé.
- Manche 12 : marque du DJ, proposée **AS Event** (à confirmer).
- Manche 16 : **accessoire porté par le DJ**, à renseigner. Variante : question sur l’anniversaire, les mariés ou la salle.

**Les manches 8 et 16 contiennent des choix “À renseigner”. Les compléter et cocher la bonne réponse avant de jouer, ou les supprimer.** Leur première solution est uniquement un emplacement d’édition, pas une réponse réelle. Retirer aussi la mention `[À PERSONNALISER]` de l’énoncé.

Exemples de pauses à adapter : « Comment s’appelle le DJ ? », « Combien de projecteurs voyez-vous sur sa régie ? », « Quelle inscription est sur son tee-shirt ? », « Combien de bougies souffle la star de la soirée ? », « Quel est le prénom de la mariée ? ». Utiliser uniquement des faits vérifiables. Pour « Qui danse le mieux ? » ou « Qui chante le plus fort ? », faire une animation micro sans classement : c’est une appréciation, pas une bonne réponse à noter.

## Importer et ajouter les extraits

Après `git pull --ff-only`, ouvrir **Manager → Quizz → Importer** et choisir les JSON dans `D:\Dev\Razzia\examples\soirees`. Les anciens quiz déjà importés dans l’application ne sont pas remplacés : les supprimer dans la régie si tu n’en veux plus.

Déposer tes MP3 dans `music`. Dans chaque question musicale : **Mes dossiers → music → Actualiser la liste → Utiliser pour cette question**. Régler début et volume, puis écouter l’aperçu et enregistrer le quiz. Choisir la version de l’artiste indiqué ; éviter une reprise non prévue par les réponses. Les titres ci-dessous sont réservés à l’animateur et ne figurent pas dans les questions.

Les extraits commencent dès l’énoncé ; le temps de réponse est de 25 secondes. Les pauses DJ ont 15 secondes. Les 10 secondes de révélation sont gérées par le jeu ; la question suivante reste manuelle. Pas de pénalité. Pour un set encore plus musical, retirer les 4 pauses : le pack devient 100 % blind test.
